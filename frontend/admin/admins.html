Manage Owners

Only one owner can be logged in at a time — logging in anywhere (any account) automatically signs out whatever session was active before it. You cannot delete the last remaining owner account.

The public site's sidebar "Owner Login" → First-Time Setup uses a dual-OTP flow (one code by SMS, one by email); once verified, the new owner sets their own password and their phone number is locked to that account — a different number will be rejected. Reset a locked number below if it needs to change. Returning owners log in with email + phone + password (no OTP).
